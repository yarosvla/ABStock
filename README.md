# ABStock — мультиагентная биржа (MVP)

## 1. Описание проекта

ABStock — учебный прототип биржи одного актива, в котором цена формируется не напрямую, а через взаимодействие агентов.

Пользователь:
- создаёт актив (тип + описание),
- запускает торги,
- наблюдает динамику цены,
- может вводить новости,
- видит, как новости влияют на поведение агентов и рынок.

Ключевая идея:
цена возникает из действий агентов, а не задаётся вручную.

---

## 2. Архитектура

Основные компоненты:

- UI (Blazor)
- Application Layer
- ExchangeEngine
- Agents
- AI Module (ChatGPT + FinBERT)

Основной поток данных:

Пользователь → UI → Application → Agents → Exchange → MarketSnapshot → UI

При вводе новости:

Новость → AI Module → NewsSignal → NewsDrivenAgent → Exchange → рынок

## 5. Бизнес-логика

До новости:
- агенты торгуют на основе цены
- биржа сопоставляет заявки
- цена меняется через сделки

После новости:
- AI анализирует текст
- формируется NewsSignal
- NewsDrivenAgent реагирует
- рынок изменяется
